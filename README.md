## Player Segmentation using K-Means Clustering

This project applies unsupervised learning to segment players based on their performance attributes using **K-Means Clustering**. The analysis follows a complete data science workflow — from data cleaning and exploration to clustering and PCA-based visualization.

---

### 📁 Project Structure

```bash
📦 Player-Segmentation-Project
├── data_preprocessing/data_cleaning.ipynb         # Data preprocessing, missing value handling, encoding
├── data_preprocessing/data_exploration.ipynb      # EDA: Distributions, correlations, feature importance
├── player_segmentation.ipynb   # KMeans clustering, Elbow method, PCA, visualization
└── dataset/                       # (Optional) Raw or cleaned dataset directory
```

---

### 📊 Dataset

- **Source:** (Synthetic data generated by ChatGPT )
- **Features:** Various performance metrics or attributes for each player
- **Target:** No target variable — unsupervised clustering

### ✅ Steps Performed

#### 1. Data Cleaning

- Handled missing values
- Encoded categorical variables
- Removed irrelevant or low-variance features

#### 2. Exploratory Data Analysis (EDA)

- Visualized distributions of key attributes
- Analyzed correlations and outliers
- Identified potential clustering features

#### 3. Clustering (Unsupervised Learning)

- Applied the **Elbow Method** to determine optimal K
- Used **K-Means Clustering** for player segmentation

#### 4. Dimensionality Reduction

- Reduced feature space to 2D using **PCA**
- Visualized clusters in PCA space

---

### 📈 Results & Insights

- **Optimal clusters identified:** K = 3
- Players segmented into three distinct groups
- Cluster profiling reveals group-specific traits (e.g., attackers, defenders, balanced players)
